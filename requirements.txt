# --- brain ---
# BOTH constraints below are load-bearing, and the --only-binary one was
# learned the hard way on 20 Sept 2026.
#
# This package ships the Claude Code CLI INSIDE the wheel, and the SDK
# resolves that bundled copy before PATH — so this line, not npm, decides
# which Claude Code the brain runs. But only the PLATFORM wheels carry the
# binary (claude_agent_sdk-0.2.156-py3-none-win_amd64.whl, ~105 MB). If no
# wheel matches, pip silently falls back to the sdist and builds a 152 KB
# py3-none-any wheel with NO CLI in it. That happened: 0.2.157 publishes no
# win_amd64 wheel, the upgrade "succeeded", _bundled/claude.exe vanished, the
# SDK fell through to npm's claude.CMD and refused to spawn a batch script,
# and the brain stopped answering. A version ceiling cannot express "must
# arrive with a binary inside"; --only-binary can, and turns that silent
# breakage into an honest "no matching distribution".
#
# The ceiling is separate: tests/test_agent_sdk_configuration.py pins four
# ClaudeAgentOptions fields as safety decisions (tools, setting_sources,
# skills, permission_mode) and tests/test_cli_path_override.py depends on
# bundled-before-PATH resolution. A 0.3 could rename or re-default any of
# them. Upgrade on purpose, then run those two files plus
# tests/test_brain_start_failure_is_spoken.py.
--only-binary claude-agent-sdk
claude-agent-sdk>=0.2.140,<0.3.0
