Anything you drop in this folder gets indexed, and Jarvis will know it well
enough to answer questions without you re-explaining.

Worth adding, based on your spec (Q57):

- `eco-pulse-notes.md` — what the project is, where it stands, what's next
- `sat-top-README.md` — the web app: stack, structure, known issues

joining the project, not for a machine — that's the level of detail that helps.
